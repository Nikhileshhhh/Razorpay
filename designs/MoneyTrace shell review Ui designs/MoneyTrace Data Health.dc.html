Four questions this page keeps separate

AVAILABILITY ≠ CAPABILITY

Database and worker answer "is the demo operational". Source capability answers "what evidence can be read". An optional source being Absent never moves the readiness verdict — that separation is the whole page.

FRESHNESS ≠ QUALITY

Projector and job lag are freshness. Duplicates, conflicts and schema failures are quality. They sit in different groups with different vocabulary, so a stale projector is never read as corrupt data.

MEASURED ZERO ≠ UNMEASURED

A measured 0 prints as 0 in tabular figures. A genuinely untracked field prints "Not measured in prototype" in muted italic-weight type with an info tooltip — never as a zero-incident win.

NOTHING IS DERIVED HERE

Every value binds to GET /v1/data-health and is schema-validated before display. No totals, percentages, trends or money arithmetic are computed in the browser.

PAGE ANNOTATIONS
Polling contract

Every 5 s only while the tab is visible. Polling stops on tab hidden, unmount, and on error — the data layer owns that, and the indicator reflects the actual state ("Auto-refresh paused · tab hidden", "Auto-refresh stopped after error"). Refresh is always available manually.

Announce transitions, not polls

The role="status" region announces only when a status changes — "Worker status changed to Stale". Identical poll results announce nothing, so a 5-second cycle never produces screen-reader chatter.

Counts reconcile visibly

The table's last row is labelled "Server-reported totals · not client-summed" and matches the metric cards exactly: 13 duplicates, 4 conflicts, 4 schema failures, 55 unsigned. A reviewer can add the column by eye and it agrees — but the number shown is always the server's.

No colour-only warnings

Elevated counts get a triangle glyph plus a tinted card plus explanatory text; capability states carry their own glyph shape (check / flask / dashed flask / struck circle). Amber is "safe warning"; red is reserved for an actual failure, which is why nothing here is red.

Never rendered

No credentials, connection strings, API keys, webhook signatures, raw database errors, hostnames or internal secret references — and no secret or configuration editor. Health is reported as a safe status envelope, not as infrastructure detail.

Accessibility contract

One h1 and one h2 per region in reading order. The source grid is a real table with a caption, scope="col" headers and th scope="row" per source; counts use definition lists in card form. Every status is icon plus text; every tooltip's content is also present as visible or accessible text, never tooltip-only. Timestamps show local time with exact UTC in the accessible name. Focus is 2px #1a63d8 at 2px offset on every control including the copy buttons. Reduced motion removes the refresh indicator's transition — the dot simply changes state.

Conflict spike behaviour

A rising conflict count changes the number and the explanation, not the framing: exact count, "quarantined and not used as authoritative truth", and the affected sources. No percentage, no spike chart, no trend arrow, and never any implication that conflicts were auto-resolved.

Never on this page

No credentials, connection strings, API keys, webhook signatures, raw database errors, hostnames or internal secret references. No secret or configuration editor, no chat, Settings, Controls, Reconciliation or Money Paths navigation, no third-party observability product framing, no confetti or "All systems operational", and no reset control — resets live in the demo controller.
