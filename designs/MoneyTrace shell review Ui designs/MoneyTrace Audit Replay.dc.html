What a reviewer must be able to reconstruct

SEQUENCE IS THE ONLY ORDER

Every row leads with its server audit_sequence in mono. Timestamps are informative and never sortable — no column headers, no date sort, no client re-ordering. Filters narrow the set; they never renumber or reorder it.

SEVENTEEN ARTIFACT TYPES

The backend type is printed verbatim on every row and card, grouped into the eight filter categories. Each category has its own glyph shape and tint, so category is never carried by colour alone.

SAFE BY CONSTRUCTION

Redacted references and safe metadata only — no secrets, signatures, raw bank or card data, PII, chain-of-thought, or provider errors. Absent fields read "Not recorded for this artifact"; withheld fields read "Redacted for current role".

THE CLIENT NEVER AUTHORS

Timeline binds to GET /v1/cases/:id/audit; export to GET /v1/cases/:id/audit/export. The bundle and its SHA-256 come from the backend — the browser never assembles a record or recomputes the hash.

REPLAY ANNOTATIONS
Order is server-owned

The sequence number is the first thing in every row and the metadata panel states outright that the timestamp is informative. Note #39's reversal timestamp (09:47) sits after #36's (11:33) — the list stays in sequence order, which is exactly the point: it never re-sorts by time.

Three labelled regions, DOM order

Timeline (322px) → selected detail (fluid, ~500px) → forensic metadata (322px), each a section with its own aria-label, in that DOM order. The timeline is a real ol; each item is a link, so arrow keys and Tab both work and selection carries aria-current.

Category never colour-only

Each of the eight categories has a distinct glyph shape — filled square, diamond, ring, triangle, circle-check, dashed square, outlined diamond, filled block — plus the verbatim backend type in mono above the event name.

Absent ≠ zero ≠ withheld

"Not recorded for this artifact" with a struck-circle glyph for fields the artifact never had (prompt/model version here); "Redacted for current role" with a lock for withheld fields (see 1b). A dash is never used for either.

URL carries the whole view

Case, category filters, cursor and selected artifact all serialise into the query string, shown at the end of the context strip. Back/forward and shared links restore the exact three-column state; filters update the URL and never reorder results.

Accessibility contract

One h1, ordered h2s per region, three labelled section landmarks in DOM order. Timeline is a semantic ol of links with aria-current on the selection and full keyboard traversal. Filters are labelled controls; every hash copy button has an accessible name carrying the full value; timestamps expose exact UTC. New result ranges announce politely. Focus is visible everywhere at 2px #1a63d8, and any drawer restores focus to its trigger.

Never in this screen

No client timestamp sorting, no locally assembled audit record or bundle, no locally recomputed hash, no raw JSON as default content, no secrets, signatures, raw bank or card data, PII, hidden labels, chain-of-thought or provider errors — and no chat, Settings, Controls, Reconciliation, Money Paths or administration navigation.
