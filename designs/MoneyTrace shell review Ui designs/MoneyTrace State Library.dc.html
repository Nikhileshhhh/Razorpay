1MoneyTrace — route & panel state library · fourteen states (desktop only, as requested)

Four conversions this library exists to prevent

UNAVAILABLE → ZERO

No dataset renders as an explanation, never as ₹0.00 KPI cards. Absent data reads "No data"; a measured zero reads 0. The two never share a treatment.

UNCERTAINTY → FAILURE

OUTCOME_UNKNOWN is violet and offers only Check status. Red is reserved for a determinate failure. Retry and Try again are different labels with different preconditions.

ACKNOWLEDGEMENT → VERIFICATION

Incomplete verification keeps exposure at full value and lists blockers. No state ever offers automatic resolution of ambiguity — the system abstains, visibly.

STALE → ACTIONABLE

A version conflict closes the modal, refetches, announces the change and moves focus to the updated heading. The old decision cannot be submitted from a stale basis.

MONEY RULE

Any preserved monetary context stays a decimal-string minor-unit value formatted with BigInt only — never Number() or parseFloat(). A failed panel re-renders the last value it already held; it never recomputes or re-derives one.

DESKTOP PLACEMENT — STATES SIT IN THEIR PARENT LAYOUT
Not a centred card everywhere. A failed KPI keeps the KPI card's footprint; a failed table keeps its header row; a failed rail keeps the rail's width. Only genuine page-level states centre.
Geometry is stable. States occupy roughly the space their content would, so a retry does not reflow the page around the reader's cursor or focus.
Shell always survives. Navigation, identity and the Synthetic Demo badge stay visible in every state where the app can load at all — including not-found.
Accessibility contract

Page-level states own the single h1; section states use an h2 or h3 that keeps the document order intact — no level is skipped to borrow visual weight. Recoverable conditions use role="status" (polite); blocked or refused actions use role="alert". Every state names its focus destination in the table opposite, and after a retry or refetch focus lands on the refreshed heading rather than being lost to the document. Each icon is an img with its meaning as the accessible name; status is never colour-only. Reduced motion removes skeleton shimmer and banner transitions.

Untrusted content is plain text

Evidence text, agent claims, model output, notes and any path or query fragment are rendered as text nodes only — never as markup, never via a raw-HTML escape hatch, and never echoed from the URL into the DOM. Long untrusted strings wrap and truncate visually with the full value in an accessible name, not in a tooltip alone.

Toasts are supplemental

A toast may echo a state, never carry it: the inline or page explanation always exists first and persists after the toast disappears. No state's only explanation is transient, and no toast contains an action that exists nowhere else.

Never in any state

No error mascot or playful illustration, no fabricated metric, no fake AI progress or "thinking" animation, no chat prompt, no raw error dump, stack trace, payload, provider or database detail, no credentials, no hidden labels or chain-of-thought, no cross-tenant existence disclosure, and no "Something went wrong" as the only explanation.
